# ITP150 Python Projects

A collection of projects completed for ITP150 Python Programming. The programs explore familiar systems through small, readable Python models.

## Projects

- **AirlineBookingSystemSharma** — a simple airline booking system.
- **FractionsSharma** — work with fraction values and arithmetic.
- **SocialNetSharma** — a small social-network model.
- **VendingMachineSharma** — a vending-machine simulation.

## Technology

Python. Each folder is a separate class project; there is no shared web app or one central launcher. The code uses classes to represent the system being modeled.

## Run a project

1. Install Python 3.
2. Clone this repository and open the project folder you want to explore.
3. Read the Python files to find that project's entry point, then run it from the repository root. For example:

```sh
python3 AirlineBookingSystemSharma/<entry-point>.py
```

Replace `<entry-point>.py` with the script in that folder that starts the program. No shared `pip install` step is required; if an individual file imports a third-party package, install it in a virtual environment first.

## Demo

These are console-based learning projects, not hosted web apps, so there is no browser demo. [Browse the source code](https://github.com/Av1Sharma/ITProgDE) and run a project locally using the steps above.
